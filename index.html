一、先定義：三類到底差在哪？

TYPE I

一般探索活動

關鍵動詞：打開

讓學生接觸平常課程較少出現的新領域、新議題、新人物與新資源，擴大興趣與可能性。

TYPE II

團體訓練活動

關鍵動詞：練工具

培養思考、研究、溝通、合作、方法學、學習策略等可跨任務使用的能力。

TYPE III

個別／小組對真實問題的探究

關鍵動詞：做真的

學生針對真實問題進行較深入探究，包含問題釐清、方法學運用、時間管理與成果呈現。

🧠

二、共同案例：假想資優生「小宇」

小宇，國二。對「城市環境、氣候、地圖與數據」特別有興趣， 常會問：為什麼同一間學校不同地方體感溫度差那麼多？

興趣：地圖、氣候、數據 強項：觀察快、問題多 弱項：有想法但方法還不完整 潛在方向：校園熱環境研究

三、實際運作：同一個學生走三類充實

按下按鈕，看小宇在每一類活動中會「接觸什麼、學會什麼、產出什麼」。

TYPE I

一般探索：先把世界打開

學校安排小宇接觸城市熱島、氣象觀測、都市設計與環境工程等不同內容。

1
接觸
聽專家短講、看熱島地圖、參訪氣象站。
2
發現興趣
小宇對「校園不同地點溫度差」特別有反應。
3
產出
不是研究成果，而是「我想繼續研究這個」的興趣方向。
TYPE II

團體訓練：把工具練起來

小宇和同學一起學會如何觀察、蒐集資料、做訪談、整理數據與安排進度。

1
研究工具
學習量測、問卷、訪談、資料整理。
2
思考工具
練習分類、比較、推論、找證據。
3
產出
完成小型練習，但重點是「會用方法」，不是先求完整研究。
TYPE III

真實探究：開始做真的

小宇把前面累積的興趣與工具，拿來處理「校園哪裡最熱、能不能改善」這個真實問題。

1
問題釐清
把「學校很熱」縮成可研究問題：哪些地點、哪些時段、差多少？
2
方法學運用
設計量測點、固定時段紀錄，搭配遮蔭與地表材質資料。
3
時間管理
排一週試測、兩週正式蒐集、整理與分析。
4
成果呈現
做出校園熱點地圖與改善建議，向老師或行政單位報告。
一句話看懂： Type I 是讓小宇「知道世界上有這個問題」； Type II 是讓他「有工具能處理問題」； Type III 是讓他「真的拿工具去解一個真問題」。

四、換情境：你能不能把概念遷移出去？

現在不談熱島。換成另一名學生「小晴」，她對校園流浪貓議題很有興趣。

情境 A：老師帶她參訪動保團體、認識獸醫、閱讀不同城市的流浪動物政策。這最接近哪一類？
情境 B：她學習訪談技巧、資料編碼、圖表製作、專案排程。這最接近哪一類？
情境 C：她實際調查校園周邊流浪貓出沒地點、訪談居民與動保人士，最後提出校園友善管理方案。這最接近哪一類？

五、最後比較：三類放在一起看

比較面向 Type I 一般探索 Type II 團體訓練 Type III 真實問題探究
核心目的 擴展接觸與興趣 培養可遷移的方法與能力 實際處理真實問題並產出成果
學生主要在做什麼 看、聽、接觸、探索 練習、操作、合作、掌握方法 研究、決策、執行、產出
成果重點 找到可能的興趣方向 學會工具與策略 完成有真實意義的研究／作品／方案
最常見誤解 不是普通「帶出去玩」 不是只做分組活動 不是單純加深加廣作業
一句話 打開 練工具 做真的
